# Ahmed Fazil — Dark Analytics Portfolio

A responsive, original dark-themed personal website featuring a professional portrait, the user-supplied analytics CV, filters and individual case-study pages.

## Open locally
Open `index.html` in a browser. All core assets are local. Google Fonts are optional; fallback fonts work offline.

## Deploy with GitHub Pages
Upload all files (including `assets/` and every `project-*.html`) to the root of a GitHub repository. In Settings → Pages, select Deploy from a branch and choose the root directory. GitHub Pages will provide the URL.

## Accuracy and privacy
The wording, experience dates, education, and selected portfolio projects follow the supplied `Ahmed_Fazil_Data_Analytics(1).pdf`. It is included unchanged as `assets/Ahmed_Fazil_Data_Analytics_CV.pdf`. Synthetic data projects are labeled. The portrait is the photo provided in the conversation. No contact form or third-party tracker is used.

## Review before publishing
Check CV and employment dates, descriptions, project outcomes and whether you want your phone and CV accessible publicly. Some project case studies summarize work; repository links currently point to the GitHub profile rather than asserting specific unverified repository URLs.


## GitHub-backed dashboard galleries
The E-Commerce, Energy, Tourism and Real Estate pages now include their real dashboard screenshots from the project repositories. Those images are served from GitHub's raw content host; the website needs internet access to display them. For fully offline/self-contained deployment, download these screenshots into `assets/` and update the HTML paths.
